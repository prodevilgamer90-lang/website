# AniVerse

Professional anime discovery frontend built with SvelteKit and Jikan API.

## Features
- Popular, airing and upcoming anime
- Search and genre browsing
- Anime detail pages
- Episode navigation
- Watchlist stored in browser localStorage
- Continue-watching/history foundation
- Responsive dark UI
- Licensed/official video-source player placeholder

## Run locally

```bash
npm install
npm run dev
```

Open the local Vite URL shown in the terminal.

## Production build

```bash
npm run build
npm run preview
```

## Important
The project supplies anime metadata/discovery and UI. Only use video playback sources that you are authorized to embed or distribute. Do not add unauthorized copyrighted streams.
